# amplifi Quotes

A quoting tool for service businesses with real pricing math: labor, travel, lodging, tiers, regional rates, parts, and recurring contracts. Pricing rules live in settings. Customers get a branded link to pick an option, accept, sign, and download a PDF.

Runs on Cloudflare Workers. Two editions from one codebase:

- **Self-deployed (free):** a Deploy to Cloudflare button puts a full copy in your own Cloudflare account on the free plan.
- **Hosted:** run by amplifi.studio.

Status: specification. See [SPEC.md](SPEC.md) (version 0.1, October 20, 2026).

Build the spec PDF: `python3 docs/spec/build_pdf.py`
