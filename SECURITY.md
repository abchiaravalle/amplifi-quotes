# Security

Report a vulnerability to **security@amplifi.studio**. Please don't open a public issue for it.

Include what you found, how to reproduce it, and which version or commit you tested. We'll acknowledge
your report within 3 business days and keep you updated while we fix it.

We ask for 90 days before public disclosure, or less once a fix has shipped. We'll credit you in the
release notes unless you'd rather stay anonymous.

## Scope

- This repository and any copy deployed from it.
- The hosted edition at amplifi.studio.

Out of scope: findings that need a compromised Cloudflare account, physical access to a device, or a
victim who installs a malicious browser extension.
